# OneNote test fixtures

Real OneNote files the `OneNote*Tests` read. They are third-party test data, kept with the
licence they were published under; nothing here is shipped in a package.

| Folder | Source | Licence | Encoding |
|---|---|---|---|
| `aspose/` | [Aspose.Note-FOSS-for-Python](https://github.com/aspose-note-foss/Aspose.Note-FOSS-for-Python), `testfiles/` | MIT, `aspose/LICENSE.txt` | desktop revision store |
| `onenote.rs/` | [msiemens/onenote.rs](https://github.com/msiemens/onenote.rs), `crates/parser/tests/samples/` | MPL-2.0, `onenote.rs/LICENSE.txt` | FSSHTTPB package (OneDrive), and a revision store with an embedded package |

Renamed on copy:

- `onenote.rs/Linked Quick Notes.one` is `joplin/notebook_with_chinese_char_on_link/Quick Notes.one`.
- `onenote.rs/Embedded Package.onetoc2` is `non-legacy/Open Notebook.onetoc2`.

The files are unmodified, as MPL-2.0 requires for distributing them.
